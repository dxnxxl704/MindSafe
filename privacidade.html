Política de privacidade

Esta política descreve como os dados são tratados na experiência atual do MindSafe e quais são os limites deste protótipo.

Última atualização: 2026

1. Quais dados são utilizados

Podem ser informados nome, e-mail, telefone, cidade e preferência de contato para personalizar o perfil demonstrativo.

2. Onde os dados ficam

Nesta versão, as informações são armazenadas somente no armazenamento local do navegador. Elas não são enviadas para um servidor, compartilhadas com terceiros ou usadas para publicidade.

3. Controle da pessoa usuária

Você pode atualizar os dados no perfil ou sair da conta. A limpeza dos dados do navegador pode apagar as informações salvas neste protótipo.

4. Dados sensíveis

Evite inserir informações que não sejam necessárias. O MindSafe não deve ser usado para registrar dados clínicos, documentos ou informações de emergência.

5. Segurança e limitações

O armazenamento local é apenas uma simulação e não oferece os controles de segurança de um serviço online completo. Antes de disponibilizar o produto em produção, esta política deve ser revisada e os mecanismos de proteção devem ser implementados.

6. Atualizações

Esta política poderá ser atualizada para refletir novas funcionalidades, formas de tratamento de dados ou exigências legais. A data no topo indica a versão mais recente.
